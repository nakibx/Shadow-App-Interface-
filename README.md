# Shadow-App-Interface-

Figma Link: https://www.figma.com/design/YIMbXYMu5oVPaMhw8U42Bl/1st-project?node-id=0-1&t=2ekETAlKtyYNcgJd-1

## ✨ Key Features

- Modern and minimal mobile UI.
- Stylish glassmorphism and neumorphism effects.
- Search bar for quick access.
- Cloud storage overview with storage indicator.
- Organized file category icons.
- User profile and menu navigation.
- Bottom navigation bar.
- Soft gradients, shadows, and rounded components.

## 🛠️ Tools & Technologies

- Figma
- UI/UX Design
- Wireframing
- Prototyping
- Mobile App Interface Design

## 🎯 Design Goals

- Create a visually attractive interface.
- Ensure simple and intuitive navigation.
- Maintain consistency in colors, spacing, and components.
- Deliver a smooth and user-friendly mobile experience.
